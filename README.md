## In production

**[zero-trust-vps-platform](https://github.com/gabzaf/zero-trust-vps-platform)**: the server, documented as case studies. Admin access only through a VPN, two layers of firewall, central logs, tested backups, every control checked against CIS and NIST.

Start with [case 02](https://github.com/gabzaf/zero-trust-vps-platform/blob/main/cases/case-02-container-platform-and-traefik-ingress/00-overview.md): the container engine was quietly letting traffic past a firewall set to block it. I found it and closed the gap.

**AI sales agent for Esteio** (private): finds and qualifies leads, drafts outreach, prepares meetings, keeps the CRM. A person approves everything sent; the agent has no way to send a message or change its own code.

**Niche content channel** (private): a test of whether a niche can grow on organic reach alone. Animated videos for a parenting audience, scripted from official health sources and produced entirely by code, three a day. **First week, zero ad spend: from 5 to 1,000+ followers and 65k+ views**; the best video reached 24k views and 1,000+ shares. A script compares formats and opening hooks on real metrics and decides what to make next.
